# SSBump Generator

Herramienta experimental para generar texturas
SSBump compatibles con Source Engine,
especialmente Left 4 Dead 2.

## Objetivos

- Conversión de Normal Maps a SSBump.
- Soporte para resoluciones de 2048x2048 o superiores.
- Exportación de texturas compatibles con VTFEdit++.
- Incorporación futura de autosombreado mediante heightmaps.
- Interfaz gráfica para configurar la conversión.-

## Tecnologías

- Python
- NumPy
- Pillow

## Instalación

python -m pip install -r requirements.txt

## Ejecución

python main.py
